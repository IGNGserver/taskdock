# TaskDock 桌面客户端归档

此目录保存历史 Electron 桌面客户端的完整源码、测试、打包配置、打包/Smoke 脚本和图标。

其中 `scripts/` 下的脚本只属于历史归档，保留的是当时的根目录路径假设；它们已从根目录命令、工作区、CI 和 Release 流程移除，不能直接作为当前构建入口运行。

桌面客户端已停止维护，不属于当前 pnpm workspace、构建、测试或 Release 流程。当前项目的活动交付范围是网页端（含自托管中枢）和 Android 端。

归档内容仅用于历史追溯；如需恢复维护，应先重新评估安全、依赖和发布流程，不要直接把本目录重新加入 workspace。
