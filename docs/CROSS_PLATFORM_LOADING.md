基线：`origin/master@4daa0d9`。网页、桌面浏览器/PWA、原生 Android 为活动范围；
`archive/desktop-client` 保持归档，不恢复 Electron 发行链。

3. Web v2 本地优先、页面读取去重和超时、当前页面独立呈现。
4. Web 预览/分页续传、原子游标和有界上传；保留本地意图。
5. Android 认证恢复、页面优先和弱网取消/进度回归。
6. 首屏定向 SQL、查询观测与真实 PostgreSQL 回归。
7. 生产 PWA、弱网、Android 设备及真实公网验收；未实测标记 NOT PROVEN。

## 验收矩阵

- 网络：5/1 Mbps + RTT 100 ms；1 Mbps/256 Kbps + RTT 300 ms；
  256/128 Kbps + RTT 800 ms。断续、丢包、黑洞另测，不能只延迟响应。
- 冷/热缓存、无缓存、过期令牌、10,000 任务/长备注、切账户、切中枢、
  中断分页、离线编辑和恢复、PWA 更新期间缺失分块。
- 缓存可操作首屏目标 P95 <= 1 s；弱网全新 Web 首批目标 6–8 s；这些均待真机证明。
- 分别记录网络、解码、落库、首帧与可交互时间，不把服务端耗时写成客户端 P95。
- 不缓存认证或 API 到共享 CDN；不跳过正文后冒进原全局游标；
  预览/部分页面不能推断删除，也不能冒充全量最新。

## 部署边界

开发不自动修改生产 DNS、Tunnel、FRP 或镜像。VPS 静态分发应同源代理 `/api`，
只对带内容哈希的构建资源长缓存；HTML/SW 重新验证。切换需保留旧资源、
记录版本和回滚点。禁止整站 Cache Everything。生产发布、部署与验收单独记证据。

  最终构建字节的 gzip/Brotli 旁车与一致性检查；哈希长缓存、壳重新验证及 Vary 契约。
