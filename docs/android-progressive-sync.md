# 安卓渐进加载与缓存一致性

## 加载顺序

1. 启动即观察本中枢、本账户的 Room 缓存，不等在线会话恢复。
2. 新缓存先请求 `/api/v2/sync/preview`：今日安排、所在目录的前 100 个任务/目录，以及设置；不读取大备注。
3. `/sync/bootstrap` 建立固定快照，返回 `snapshotId`、基准游标 `C`、页数与过期时间。
4. 每批最多 200 条，目标正文 512 KB；单个实体超过此大小时独占一页。备注排在最后。页面写入与下一页编号同事务提交，失败继续从该页重试。
5. 只有全部页面完成才清除未出现在快照中的非待同步行，并在同一事务提交全局游标 `C`。随后上传 Outbox、消费 `C` 之后的增量。首屏、详情、目录优先读取均不改变全局游标。
6. 快照有效期 30 分钟；过期重建，旧缓存与本地修改保持可用。PostgreSQL 页面持久化，支持 API 重启与多实例；内存模式仅用于开发。

旧中枢没有分批能力时（能力接口 404 或明确不支持）退回完整 v2 快照。错误响应不能当空快照使用。断网、鉴权失败、后台加载和完整空目录分别展示，不把“尚未加载”冒充“没有数据”。

## 一致性与身份

- 中枢在数据库迁移中生成永久 `hubId`，通过认证登录/刷新响应返回。客户端按 `hubId + ownerId` 使用独立数据库；已认证的地址别名共用空间，替换中枢使用新空间。没有身份的旧中枢按地址使用 `unverified:` 空间，不能直接并入已认证空间。
- 请求绑定身份和会话代次；停止同步取消 HTTP 和协程；写入事务再次验证身份。令牌正常轮换不等于新登录，注销或重新登录提升会话代次。
- `sync_guards` 按 mutation 引用计数保护直接实体和级联实体。单个 ACK 不能解锁仍有操作的行。存在冲突的实体保留后续依赖操作；用户丢弃后重新获取权威快照。
- 被保护的远端变更写入 `remote_changes`，与拉取游标同事务提交；解除保护后对账，不能跳过变更后永久丢失它。
- 日期创建、安排创建/复制/移动可能返回已有服务端 ID。此类操作单独推送；同一事务重写本地关联、后续队列引用和保护，再推后续操作。应用实际返回版本，避免只清 pending 标志。
- 今日列表按日期 JOIN Room 的安排和任务，订阅双方变化。展示日期不会创建本地日期节点；写操作创建日期在事务内完成。

### 存量迁移

Room v8 → v9 新增同步日志与查询索引，不删除现有任务、队列或游标。旧的 `devtodo_local.db` 不包含中枢身份，无法证明其中离线操作属于当前地址；保留原数据库，不自动上传。设置提供“导出旧缓存与离线队列”，备份含任务内容但不含登录凭据；核实归属后再人工恢复。新空间首次须联网加载，不能承诺升级时直接显示旧的未隔离缓存。

PostgreSQL `0011_sync_bootstrap.sql` 增加中枢身份、快照元数据及页面表；既有业务数据和同步记录不变。回退应用版本时保留新增表、不要回滚已执行 migration 或重置中枢 ID。

## 查询与观测

- 目录任务按 100 条扩展查询窗口；SQL 统计完整本地目录数量，不拿已加载任务数当总数。
- 文件夹统计只读轻量位置/状态字段，在后台线性汇总；不为每个目录重复扫描整棵任务树。
- 日历按当前月份查询日期与计数；今日使用 JOIN，避免逐任务 N+1。
- PostgreSQL 首屏和单任务详情直接定向查询，不调用账户全量 `prepare()`；旧完整接口兼容保留。
- PostgreSQL 快照在同一个 REPEATABLE READ 事务中按 ID keyset 扫描，直接落入不可变页面表；只保留查询小批与当前页面，不在 API 内存中拼接全账户的大备注快照。元数据与全部页面同事务可见。
- 中枢同步响应提供 `Server-Timing: sync;dur=…` 并记录路由、耗时、响应字节，不记录正文或凭据。安卓调试日志记录已完成页数与行数。

服务端基线脚本（仅隔离空数据库）：

```sh
DATABASE_URL=<隔离测试库> pnpm exec tsx scripts/sync-bootstrap-benchmark.ts
```

默认 10,000 任务，每条 2,000 字备注，报告完整快照和首屏预览的 5 次样本中位数/最大值、响应大小、快照构建耗时和首批大小。这不是手机首屏 P95，不能用它宣称真机达到 1 秒缓存首屏或 2～3 秒无缓存首屏。

2026-10-13，本地 PostgreSQL 17.6 的一次实测（上述默认数据，5 次样本）：完整快照 65,007,286 字节，中位数 802 ms、最大值 1,299 ms；首屏预览 51,076 字节，中位数 24 ms、最大值 55 ms。固定快照构建 6,872 ms、177 页、首批 102,532 字节。构建期间首屏已可用；数据规模、网络和手机性能不同，结果不能直接外推。
