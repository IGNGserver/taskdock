# 手机中枢加载优化实施记录

## 基线（2026-10-18）

基线 `b746161`。Android 原生 Compose + Room；中枢 Fastify + PostgreSQL。
已有 preview、固定分页快照、原子续传与增量游标，不另建第二套缓存。

源码确认的复现场景：

- 详情先显示缓存，再收到同 ID 新版本：编辑框仅按 ID 初始化，仍保留旧内容。
- 初次启动今日列表为空但远端未返回：`dataReady` 提前为 true，误报没有安排。
- edge-to-edge 根 Scaffold 的 Insets 为零，根横幅处于页面安全区之外。
- 前台长期停留且 WebSocket 通知丢失：没有周期增量核验。
- 游标过期调用整包快照；大量 Outbox 在拉取前串行上传。

历史 CI：quality [39036914310](https://github.com/IGNGserver/taskdock/actions/runs/39036914310) 通过；
Android [39036914395](https://github.com/IGNGserver/taskdock/actions/runs/39036914395) 44 项中 8 项失败。
同步夹具漏传必填 `referenceId`，界面用例还有过期文案及交互等待问题；历史失败不能当成本次验证通过。

## 实施顺序

1. 基线复现及防回归测试。
2. 详情草稿对账、完整性/新鲜度状态、页面标题下的持久提示。
3. 前台定时核验、当前页优先、有界等待、上传让出和分页恢复。
4. 后端覆盖范围、快照合并/清理和索引、真实 PostgreSQL 与 Android 联合验证。

## 性能口径

目标为缓存可操作首屏 P95 ≤ 1 秒、正常网络无缓存首批 ≤ 3 秒、
实时链路正常时跨端更新 P95 ≤ 2 秒。基准数据为 10,000 任务及每条 2,000 字备注。
服务端耗时不等于手机首屏耗时；MockWebServer 测试不等于真实公网验收。
分别记录请求、响应字节、解析、落库和首屏呈现；没有设备实测的指标保持“未证实”。

本地验证副本：`$HOME/.build/todo-list工具/mobile-hub-loading/source`，
创建前磁盘可用 142 GiB。依赖和产物只写 scratch，重型构建与 PostgreSQL 集成交给 PR CI。

## 实现契约

- 页面状态与全局完整性分离：页面请求记录加载、失败及接收时间；全局
  `confirmed:<owner>` 只在增量全部落库的事务内写入。预览的游标永不推进全局游标。
- 前台每 60 秒做一次增量校验；120 秒未确认、设备时钟回拨或没有确认记录时提示尚未核验。
  周期校验只走增量游标，不再强制刷新当前页面；页面预览只发生在进入/切换页面和手动刷新时。
  后台停止周期请求，回前台恢复。页面请求按键合并并保留最多约 48 个近期状态。
- 页面请求 12 秒、手动下拉等待 15 秒、整轮同步 45 秒预算。下拉结束不取消引擎持有的
  同步，整轮超时保留已提交页面和 Outbox，之后退避重试。超时不会伪装成最新状态。
- 上传最多每批 100 项、目标 256 KB，单项仍允许既有 900 KB 上限；上传前及批间拉取，
  本地待提交行仍由引用计数保护，远端影子和游标原子提交。
- 游标过期和被拒操作恢复走分页 bootstrap；只对明确不支持分页的旧中枢回退整包。
- 预览新增 `cursor`、`checkedAt`、`coverage`（目录、日期、100 条窗口及各集合 `HasMore`）。
  这是覆盖范围提示，`complete` 仍恒为 false；不能根据窗口之外缺失的实体推断删除。
- 标题/备注按远端版本对账，未编辑字段立即更新，已有草稿显示冲突提示。
- 横幅由每个 Workspace 的 topBar 容器渲染，位于系统安全区及标题下方；失败常驻并提供重试，
  成功后收起为最后核验时间。只有确认时间超过新鲜度窗口、首次加载失败或真实错误时才显示
  “显示缓存”；正常后台校验显示为带小进度的“上次核验”紧凑状态。今日页和详情不把尚未
  返回的响应冒充空状态。
- PostgreSQL 首屏查询使用目录有序索引；任务标题、状态、备注编辑只读取单任务投影，
  复用原领域验证，行、变更记录、幂等收据仍在同一事务。其他复杂变更保留既有领域路径。
- 同进程并发 bootstrap 合并；跨实例复用同游标且剩余有效期超过 5 分钟的已完成快照。
  过期快照每分钟后台最多删除 2 个，副本使用 SKIP LOCKED，不在首屏请求中做全局清理。
- v2 响应禁止代理缓存。关键接口带 Server-Timing 和请求 ID；Android 日志只记路由类别、
  接收/解析/应用耗时和数量，不记正文或凭据。

## 迁移和兼容

`0012_mobile_sync_read_indexes.sql` 只增加索引，不迁移或删除业务数据；Room 使用已有
`sync_meta` 表存储确认时间，不升 schema。旧中枢可继续使用现有协议；新增预览字段为可选扩展。
回滚应用可保留这些索引和元数据。首次升级数据库应按既有迁移通道执行，索引建立期间按部署维护窗口处理。
