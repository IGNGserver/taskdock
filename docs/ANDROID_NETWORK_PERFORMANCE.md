# Android 通信与体验优化

## 范围与基线

基线：`4b51b33`。原生 Compose / Room / OkHttp；复用现有 Outbox、版本保护、分页快照和增量协议。
不改 Web 交互，不部署或发布，不记录正文、账户、地址、令牌和查询参数。

## 实施顺序

1. 增加脱敏 HTTP 分阶段追踪和服务端请求关联；确认现场 APK、中枢 commit、入口一致。
2. 普通待上传和后台补全采用紧凑提示；页面新鲜度与全局补全分离，成功操作静默。
3. 安卓接入已有目录网络分页，保留缓存和乐观编辑；页面成员、续页与失败独立管理。
4. 限定认证恢复预算，修复实时关闭/认证恢复，减少重复拉取，为增量添加字节预算。
5. 单测、真实 PostgreSQL、模拟器与真机弱网验收；结果按运行环境分别记录。

## 观测口径

`TaskDockNetwork`：route 类别、DNS、连接（含 TLS）、TLS、响应头、总耗时、线上响应体字节、
压缩编码、连接复用、HTTP 状态、脱敏请求 ID。响应头时间包含连接与请求等待，不冒充纯服务端 TTFB。
`TaskDockSync`：接收、解析、Room 应用与分页数量。日志不包含业务 ID、URL 或正文。
服务端定向页面、详情和同步响应返回 `Server-Timing`、`X-Request-Id`，可关联两端。

同设备同账户分别记录：缓存首屏、无缓存首批、认证恢复、通知到拉取、落库到呈现、全量完成，
以及请求次数和传输字节。服务端历史基准不等于本次设备 P95。

## 验收目标与矩阵

目标而非已达成结果：缓存首屏 P95 ≤1 秒；正常网络无缓存首批 ≤3 秒；实时链路健康时跨端可见 ≤2 秒；
普通本地操作目标 100ms 内反馈。正常 pending 不展开警告，失败不清空旧列表、不丢草稿或队列。

矩阵：有效/过期/撤销令牌；冷热缓存；大目录与长备注；RTT 300ms/1s、限速、黑洞、断网恢复；
Wi-Fi/移动网络切换；WS 握手后不认证、主动关闭、断线与通知遗漏；分页失效/中断；
并发编辑、响应丢失、积压和冲突；切换账户/中枢后旧请求不能落库。

本机当前无 adb 设备，真机与实际公网 P95 尚不可测。CI 模拟器不能替代此项验收。
大正文按需同步为后续独立协议项目，本轮保留完整离线副本；不能跳过正文后推进原全局游标。

## 已实现的机制

- 当前目录通过 `/tree/children?limit=100&cursor=…` 独立加载；游标作为不透明值编码。
  失效时仅重建页面成员，失败保留上一页及续页位置，不删除 Room 行、不推进全局同步游标。
  页面成员包含本地接受的修改与后续增量，避免旧首页覆盖 ACK 后新建项；SQLite 参数按 800 项分块。
- 当前页核验与全账户完成分别展示。普通 pending、已有内容下的后台检查与补全保持紧凑；
  登录、协议、冲突、拒绝和真实错误不隐藏。低速核验的新鲜度窗口覆盖 180 秒调度周期。
- 认证 challenge 和 refresh（包括锁等待）共享 15 秒预算；取消恢复关闭该次请求，不取消其他页面请求。
  重复前台回调复用进行中的恢复；继续保留刷新候选令牌以处理服务端已提交但响应丢失。
- WS 区分连接中、握手和认证 ready；回复主动关闭帧，10 秒未 ready 则重连。
  仅认证 ready 重置退避，实时不可用时前台以至多 15 秒间隔兜底，后台不做周期轮询。
- Bootstrap 每约 8 秒在已提交页边界让出，报告 Continuing 而非失败/最终成功；保留 checkpoint 后续跑。
  已有全局游标时仍恢复未完成 checkpoint；WidgetWorker 对 Continuing 追加新的续跑任务，
  不累计网络失败的指数退避，避免等待时间超过快照有效期。
- 每个成功上传批次后的拉取保留，删除重复的整轮末尾拉取；不改变依赖分批和 pending guards。
- 增量 JSON 默认目标 512 KiB，安卓请求 256 KiB；连续前缀推进游标，超大单实体独占一页。
  这是响应传输预算，不是数据库查询内存上限，也不是字段级差分。
- 快照清扫同事务更新 reconciliation generation；目录旧响应最多重读一次，最终应用在同事务检查代际。
  详情也拒绝跨代际响应。其他引擎推进共享 Room 游标时，主界面重读可见目录，避免 Widget 消费变更后漏项。
- 完整缓存可用后使用响应式 Room 目录聚合，不让旧页面聚合覆盖后续任务变化。

## 回滚与兼容

没有新 migration；使用现有 `sync_meta` 存储快照代际，旧客户端忽略该键。
新增 `maxBytes` 为兼容查询参数，旧中枢可忽略；默认服务端响应形状不变，客户端必须遵守既有 hasMore。
回滚保留 Room、Outbox 和现有快照表，禁止清空缓存/同步队列。没有更改中枢地址、代理、凭据或部署配置。
